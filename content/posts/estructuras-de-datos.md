Cada estructura de datos se parece a algo que ya conoces. Repásalas con tarjetas ✦

```flashcards
Pila (stack) :: Una torre de platos 🍽
Cola (queue) :: La fila del helado 🍦
Árbol :: Un árbol genealógico 🌳
Grafo :: Un mapa de metro 🚇
Diccionario :: Una agenda de contactos 📒
Array :: Una caja de huevos 🥚
```

## ¿Por qué esas analogías?

- **Pila**: solo puedes coger el plato de arriba → *último en entrar, primero en salir*.
- **Cola**: el primero que llegó es el primero que se va → *primero en entrar, primero en salir*.
- **Array**: cada huevo tiene su hueco numerado.
