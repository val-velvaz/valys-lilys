Every data structure looks like something you already know. Review them with cards ✦

```flashcards
Stack :: A tower of plates 🍽
Queue :: The line at the ice cream shop 🍦
Tree :: A family tree 🌳
Graph :: A subway map 🚇
Dictionary :: A contact book 📒
Array :: An egg carton 🥚
```

## Why those analogies?

- **Stack**: you can only take the plate on top → *last in, first out*.
- **Queue**: the first one who arrived is the first one to leave → *first in, first out*.
- **Array**: every egg has its own numbered slot.
