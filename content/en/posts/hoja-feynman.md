This is the tool I use to write **every post** on the blog. It saves itself while you write, and at the end you can export it as a `.md` file to put in `content/en/posts/`.

```hoja-feynman
concepto:
```

> [!IDEA]
> The exported file already has the *front matter* (title, date, section, tags…). Just move it to `content/en/posts/` and run `node scripts/build-index.mjs`.
