Jede Datenstruktur ähnelt etwas, das du schon kennst. Wiederhole sie mit Karteikarten ✦

```flashcards
Stapel (Stack) :: Ein Tellerstapel 🍽
Warteschlange (Queue) :: Die Schlange vor der Eisdiele 🍦
Baum :: Ein Stammbaum 🌳
Graph :: Ein U-Bahn-Plan 🚇
Wörterbuch (Dictionary) :: Ein Adressbuch 📒
Array :: Ein Eierkarton 🥚
```

## Warum diese Analogien?

- **Stapel**: Du kannst nur den obersten Teller nehmen → *zuletzt rein, zuerst raus*.
- **Warteschlange**: Wer zuerst kam, geht zuerst → *zuerst rein, zuerst raus*.
- **Array**: Jedes Ei hat seinen eigenen nummerierten Platz.
